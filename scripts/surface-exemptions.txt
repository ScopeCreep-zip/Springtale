# Routes that do not yet have a command-line verb and/or a web
# DataProvider method.
#
# This is a ledger of gaps, not a permission slip. `check-surface.sh`
# fails on any NEW uncovered route, and fails on an entry naming a route
# that no longer exists, so the file can only ever shrink.
#
# A route that should never have a verb or a method does not belong
# here — it belongs in `surface-not-surfaced.txt`, with its reason.
#
# Columns: <route>  <cli|provider|cli provider>
#
# The ledger is EMPTY. Every route the daemon serves has a
# command-line verb and a web provider method, or an entry in
# `surface-not-surfaced.txt` saying why it never will.
#
# Keep it that way: a new route with no surface is a gap, and a gap
# recorded here is a promise to close it, not permission to leave it.
